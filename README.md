#PS 07 — FreshRoute: Intelligent Decision Support for Perishable Produce Distribution
# FreshRoute AI — Hackathon MVP


FreshRoute AI is a Streamlit prototype for perishable-produce allocation, explainable dispatch planning, scenario replanning, and rule-based discount simulation.

## Features
- Simulated produce batches, purchase costs, market prices, and remaining shelf life.
- Destination demand, route travel time, transport cost, and capacity constraints.
- FIFO baseline and mixed-integer linear programming (MILP) allocation optimizer using SciPy.
- Checks for destination capacity, demand limits, and arrival before expiry.
- What-if controls for demand, transport delays, and capacity.
- Rule-based discount recommendations with an explicit sell-through assumption slider.
- CSV export of the FreshRoute dispatch plan.
- Financial breakdown of revenue, transport cost, starting inventory cost, and estimated net value.

## Run on Windows (VS Code terminal)
1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
4. Start the app:
   ```powershell
   python -m streamlit run app.py
   ```
5. Open the local URL printed in the terminal, usually `http://localhost:8501`.

## Methodology and limitations
- **Data:** generated by the app; no live feed or real distributor dataset is used.
- **FIFO baseline:** processes batches by earliest expiry and checks destinations in a fixed order.
-**FreshRoute MILP:** maximizes shipped sales revenue minus transport cost, subject to inventory, route capacity, destination-commodity demand, and shelf-life feasibility. Purchase cost is fixed across allocation plans in this simulation.
- **Net value:** shipped-unit sales revenue minus transport cost on shipped units and purchase cost of all starting inventory.
- **Spoilage estimate:** all unallocated inventory is treated as unsold/spoiled in this simplified single-period simulation.
- **Discount simulator:** recommendations use transparent shelf-life rules. Sell-through is a user-selected assumption; discount effects are not fed back into the optimizer.
- **Performance:** do not claim FreshRoute outperforms FIFO unless displayed test results support that claim. Equal outcomes can occur in some scenarios.
- **Not production-ready:** test against representative real data and document scenarios before operational use.

## Dependencies
See `requirements.txt`. The optimizer requires SciPy with `scipy.optimize.milp`.
